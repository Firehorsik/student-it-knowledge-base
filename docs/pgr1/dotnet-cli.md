| Polecenie | Przykład użycia | Co opisać |
| :--- | :--- | :--- |
| `dotnet --version` | `dotnet --version` | Sprawdzanie zainstalowanej wersji zestawu .NET SDK. |
| `dotnet --list-sdks` | `dotnet --list-sdks` | Wyświetlanie wszystkich dostępnych wersji SDK. |
| `dotnet new list` | `dotnet new list` | Wyświetlanie dostępnych szablonów projektów. |
| `dotnet new console` | `dotnet new console` | Tworzenie aplikacji konsolowej w bieżącym katalogu. |
| `dotnet new console -n` | `dotnet new console -n MyApp` | Tworzenie aplikacji konsolowej w nowym katalogu o podanej nazwie. |
| `dotnet restore` | `dotnet restore` | Pobieranie zależności wymaganych przez projekt. |
| `dotnet build` | `dotnet build` | Kompilowanie projektu i wyświetlanie komunikatów o ewentualnych błędach. |
| `dotnet run` | `dotnet run --project MyApp` | Budowanie i uruchamianie wskazanego projektu. |
| `dotnet clean` | `dotnet clean` | Usuwanie plików wygenerowanych podczas kompilacji projektu. |
